# first-godot-game

Godot 4.7 2D 闪避游戏。玩家控制角色躲避从屏幕边缘出现的敌人，存活越久分数越高。

## v0.4.0 已实现

- 三种敌人类型：侦查兵（小/快/橙色）、普通（红色）、坦克（大/慢/紫色）
- 权重随机生成（20%侦查 / 30%坦克 / 50%普通）
- 道具系统：护盾（挡一次伤害，蓝色光环）、双倍分数（2x，金色光晕）
- 道具每 5 秒屏幕内随机生成，带浮动动画
- 护盾破裂时轻量屏幕震动
- 拾取音效、护盾破裂音效
- 数据版本 1，兼容旧存档

## v0.3.0 已实现

- 程序化音效系统（SoundManager 自动加载）
- 击中音效、游戏结束音效、敌人出现音效、开始游戏音效
- 所有音效通过代码生成，无需外部音频文件
- 摄像机震动效果（击中时屏幕抖动）
- 击中的延时游戏结束音效节奏
- 数据版本 1，兼容旧存档

## v0.2.0 已实现

- 敌人从屏幕四边随机生成
- 碰撞检测（碰即失败）
- 分数系统（存活时间 → 分数）
- 难度递增（每 10 秒加速敌人生成）

## 启动

使用 Godot 4.7 打开 project.godot，运行主场景 `res://scenes/Main.tscn`。

### 操作方式

- ↑ ↓ ← → 或 WASD：移动玩家
- 点击"Start Game"：开始游戏
- 点击"Restart"：重新开始

## 项目结构

```
first-godot-game/
├── scenes/
│   ├── Main.tscn          # 主游戏场景
│   ├── Player.tscn        # 玩家场景
│   ├── Enemy.tscn         # 敌人场景
│   └── PowerUp.tscn       # 道具拾取场景
├── scripts/
│   ├── main.gd            # 游戏管理器（状态、分数、生成）
│   ├── player.gd          # 玩家移动、碰撞、道具效果
│   ├── enemy.gd           # 敌人类型系统（侦查/普通/坦克）
│   ├── game_over.gd       # 失败界面逻辑
│   ├── sound_manager.gd   # 程序化音效生成（自动加载）
│   ├── camera_shake.gd    # 摄像机震动效果
│   └── power_up.gd        # 道具拾取（护盾/双倍分数）
├── assets/
│   ├── sprites/           # 图片资源（占位）
│   └── audio/             # 音频资源（占位）
├── ui/
│   └── GameOver.tscn      # 失败界面
├── AGENTS.md              # 工作规则
├── PROJECT_GOAL.md        # 产品上下文
├── README.md              # 发布说明
└── .omo/                  # 自动化脚本
```

## 跨环境继续开发

完整产品上下文、已完成版本和持续开发规则保存在 PROJECT_GOAL.md，
AGENTS.md 会要求新环境在修改前读取该文件。换电脑后克隆仓库即可恢复开发上下文。

每轮开发还会检查仓库的开放 GitHub Issues：可执行的玩家建议会先回复纳入版本，
完成发布后再回复提交、标签和上线状态并关闭；需要补充信息的建议会回复问题并保持开放。

Issue 处理结果同时写入 PROJECT_GOAL.md 和本文件（双写），确保换环境后仍可追踪。
